# ZV-E10 II 专属水印工坊

一个专为 Sony ZV-E10 II 制作的本地照片水印工具。导入照片后，程序会自动读取 EXIF 参数，生成带相机信息的白色或黑色参数水印。

## 功能

- 自动读取相机、镜头、光圈、快门、ISO、焦距、35mm 等效焦距、测光和闪光灯信息
- 支持 JPG、PNG、WEBP，以及 Sony ARW 内嵌预览
- 所有参数均可手动修改
- 提供象牙白、曜石黑两种水印主题
- 提供完整参数、精简参数两种布局
- 默认在浏览器本地处理照片；云端 AI 美化仅在用户勾选同意并点击发送后上传当前照片
- 可选原尺寸高画质 JPG（98%）或无损 PNG
- 支持原尺寸、长边 2048px、长边 1080px 三档导出；尺寸包含水印，小图不放大，单张及批量均可使用，尺寸选择可保存到预设
- 可使用滑杆自由调整水印条高度，文字和图标会同步适配
- 支持一次选择多张照片，逐张读取 EXIF 后批量导出 ZIP
- 提供分页缩略图列表，可切换预览、移除照片；每张分别保存本次旋转和水印参数修改，也可单独导出当前照片。缩略图按页依次生成，照片与调整不写入浏览器存储
- 相机／镜头图标支持透明或纯色留白自动裁边、拖动与键盘微调、恢复完整图片及浅／深色背景预览；应用前可取消，原有背景会保留
- 水印使用白色 ZV-E10 II 真实机身造型
- 可上传自定义相机／镜头图标（PNG、JPG、WEBP，每张不超过 10 MB），保留透明背景和比例，适用于预览、单张及批量导出
- 内置可点选的相机／镜头图库：ZV-E10 II 白色、α6700、α7 IV、16-50 II、18-135 OSS、35 F1.8 OSS、18-105 F4 G、16-55 F2.8 G；图库选择只改变图片，不更改 EXIF 参数
- 自定义图标自动缩小至最长边 512 像素，仅保存在当前浏览器，所有水印预设共用；支持分别恢复默认图片
- 大图使用较小的实时预览，导出时重新读取原图，保留原始照片像素并添加水印条；原尺寸导出仍需要足够的设备内存
- ARW 内嵌预览分块扫描，批量导出逐张处理并释放临时图像和画布
- 每批 ZIP 的照片内容最多约 96 MiB；达到限制时会导出已完成的照片并明确提示剩余文件，请分批导入或改用 JPG

## 本地运行

需要 Node.js 22 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

打开 `http://localhost:3000` 即可使用。

## 构建

```bash
pnpm run build
pnpm run start
```

## RAW 说明

浏览器不能直接显影 ARW。导入 ARW 时，工具会读取 EXIF 并使用文件内嵌的预览图；需要最高分辨率时，请先把 RAW 转成 JPEG 再导入。


## 图库素材

新增产品照片来源及原图地址见 [public/gear/SOURCES.md](public/gear/SOURCES.md)。素材随应用提供，选择和导出时无需访问第三方图片服务；镜头图库使用透明背景，相机图片保留原有背景。

## 云端 AI 美化

支持 OpenAI 兼容的同步 `POST /v1/images/edits`（multipart `image`、`model`、`prompt`、`n=1`）与 `GET /v1/models`。需选择服务实际支持的图片编辑模型，模型列表中的聊天模型不一定可用。兼容 `data[0].b64_json` 或可跨域下载的 HTTPS `data[0].url`。参考 [Sub2API 接口说明](https://github.com/Wei-Shaw/sub2api/blob/main/README.md)。

API Key 只留在页面内存，不写入浏览器存储或仓库。请求发生前需确认发送；生成可能收费，取消等待不保证取消服务端任务。上传的是原图最长边 1536px、去除 EXIF 的 PNG，ARW 使用内嵌预览。风格和程度通过提示词控制，效果以模型结果为准。结果先对比，应用后单张和批量导出均使用 AI 图片实际尺寸，拍摄参数仍读取原文件；每张可恢复原图，刷新后清除 AI 结果。局部细节、身份和构图保留不能保证，应由用户检查。

### HTTP 局域网 API 的本地连接版

GitHub Pages 为静态 HTTPS 网站，不能直接连接 HTTP 局域网接口；同时服务需允许跨域。仓库提供仅监听本机 127.0.0.1 的连接服务，在同一个本地页面转发到指定 API。

```powershell
pnpm install --frozen-lockfile
pnpm run build:pages
$env:AI_API_BASE = "http://你的局域网服务:端口/v1"
pnpm run start:cloud
```

打开 `http://127.0.0.1:5188/zve10-watermark-app/`，展开云端 AI 美化，保留 `/api/cloud` 地址，填写 Key 并读取模型。此连接版只供本机使用，不对外暴露；上游地址固定于启动环境变量，不接受请求覆盖。支持用户配置的 HTTPS 兼容服务直连，但服务须允许浏览器跨域。Key 不应放入公开前端构建或 GitHub。

验证使用模拟图片接口，不代表任意第三方模型都已验证。真实服务需要用户在页面输入 Key 后进行验证。

云端 AI 支持自定义修改对话：输入自己的修改要求，默认基于最新预览（或当前已应用结果）继续，也可选择原始照片。每轮上传所选图片并发送本次要求；对话记录仅供当前页面查看，不额外发送历史文本。请求失败、取消会保留上一版预览。每张照片显示最近 10 轮文字记录，切换照片或刷新清除；点击“清空对话”只清除文字，原图始终可恢复。每次发送均可能产生 API 费用。
